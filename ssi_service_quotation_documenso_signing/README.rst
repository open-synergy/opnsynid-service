===================================================
Service Quotation - Documenso Signing Integration
===================================================

This module integrates **Service Quotation** (``service.quotation``) with
**Documenso**, an open-source digital signature platform.

It adds a *Documenso* tab to the Service Quotation form view, allowing users
to manage signature requests directly from the quotation record.

Configuration
=============

No additional configuration is required. Install this module along with
``ssi_connector_documenso_signing`` and configure the Documenso connector
through the system settings.

Usage
=====

Open any Service Quotation record. A new **Documenso** tab will appear in
the form view, listing all signature requests linked to that quotation.

Work Instruction
================

* `Approve Service Quotation <docs/service_quotation/index.html>`_
* `Create Signing Request for Service Quotation <docs/service_quotation/index.html>`_
